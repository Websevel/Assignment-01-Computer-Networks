**Network Protocol Analysis **– HTTP, HTTPS, and QUIC
**📌 Overview**

This project analyzes different web protocols (HTTP, HTTPS, and QUIC) using Wireshark network traces. The tasks involve capturing packets, identifying protocol behaviors, and answering detailed questions about requests, responses, TLS handshake, and QUIC features.
